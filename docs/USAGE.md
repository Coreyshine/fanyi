# fanyi 使用指南

> 一句话：**菜单栏有「译」图标 + 浏览器装了扩展 = 打开外文网页自动变中文**。
> 平时你什么都不用点；下面是各功能的详细说明。

---

## 一、第一次使用（一次性准备，共两步）

### 第 1 步：启动服务端

- 双击 **Fanyi.app**（或终端运行 `~/Projects/fanyi/build/fanyi-server`）
- 屏幕右上角菜单栏出现「**译**」图标 = 服务就绪
- 想开机自启：系统设置 → 通用 → 登录项 → 添加 Fanyi（装好后以后不用管）

### 第 2 步：安装浏览器扩展（每台浏览器一次）

- **Chrome / Edge**：地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
  → 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选择 `extension/` 文件夹
- **Firefox**：加载 `extension-firefox/` 文件夹（manifest 已是 Firefox 专用版），
  到 `about:debugging#/runtime/this-firefox` →「临时载入附加组件」
- 以后代码更新了：回到扩展管理页，点 fanyi 卡片上的**刷新图标**即可

> 注意：扩展只是"手"，翻译的"脑子"在服务端。**托盘图标没开，翻译不会工作。**

## 二、日常使用

### 1. 网页自动翻译（默认开启，无需任何操作）

- 保持托盘「译」在运行，正常上网即可
- 打开**外文占比超过 60%** 的页面（阈值可在设置页调）→ 自动整页翻译，逐段流出替换
- **中文页面不会翻译**（外文占比不足，不浪费算力）
- 这些内容默认不翻：代码块（`code`/`pre`）、输入框里已填的内容、正在编辑的区域

### 2. 悬浮开关（每个页面右上角的胶囊按钮，可拖动）

| 显示状态 | 含义 | 点它会 |
|---|---|---|
| 灰 ·「译 · 点击翻译本页」 | 页面外文不足阈值，没自动翻 | 强制翻译本页 |
| 蓝 ·「翻译中 n/m」 | 正在逐段翻译 | — |
| 绿 ·「已译 n 段 · 点击还原」 | 翻译完成 | 还原原文（再点又翻译） |
| 红 ·「服务未运行」 | fanyi-server 没开 | 尝试重连（先去开服务） |
| 灰 ·「已停用」 | 托盘菜单里全局暂停了 | —（去托盘恢复） |

位置拖动后会记住。

### 3. 输入翻译（在任何输入框里用中文"打"外文）

在任何**输入框 / 多行文本域 / 富文本编辑区**（包括网页评论区、邮箱正文、在线文档）：

1. 在输入区域**右键** → 出现「**输入翻译内容**」按钮（输入框右上角浮动按钮，全浏览器通用；
   Chrome/Edge/Firefox 另有原生右键菜单项）
2. 点开面板：**用中文输入**想表达的内容 → 下拉**选目标语言**（21 种，记住上次选择；
   默认与页面翻译方向互补：页面英→汉时，输入翻译默认汉→英）
3. 点「**翻 译**」→ 译文自动填入原输入框的光标处，面板自动关闭
4. 填错了按 `Ctrl+Z`（⌘Z）可撤销

### 4. 工具栏按钮（浏览器右上角的「译」图标）

点浏览器工具栏上的「译」图标弹出快捷面板：
- **本页翻译** 开关：等同点页面悬浮开关（翻译/还原）
- **翻译总开关** 开关：等同托盘里的全局暂停
- **打开设置页** 按钮；面板顶部小圆点显示服务是否在线

### 5. 托盘菜单（菜单栏「译」图标）

- **打开设置…**（⌘S）：浏览器打开设置页
- **翻译：开（点此暂停）**（⌘T）：全局总开关；暂停后所有页面悬浮开关显示"已停用"
- **退出 fanyi**（⌘Q）

### 6. 设置页（http://127.0.0.1:8765/settings）

| 设置 | 说明 |
|---|---|
| 语言方向 | 默认英→汉，可改任意方向（30+ 语言） |
| 外文比例阈值 | 默认 60%，越高越不容易误触发 |
| 精准模式 | 贪心解码，同一文本结果完全一致，推荐开 |
| 并行翻译段数 | 越大整页越快、内存略增；低配电脑 1-4 |
| 空闲自动卸载 | 默认 10 分钟不用就释放模型内存，0 = 常驻 |
| 模型路径 / 端口 | 一般不用动；端口修改需重启服务 |

## 三、常见情况

- **悬浮开关变红**：服务没开 → 打开 Fanyi.app，再点一下开关自动重连
- **首次翻译慢**：模型加载需 1-3 秒（外加 macOS 首次编译 Metal 着色器），之后常驻秒翻
- **改了语言方向**：对之后新打开的页面生效
- **内存占用**：翻译时约 2.5 GB（模型在工作），空闲 10 分钟后自动降回几十 MB
- **某些页面没自动翻**：外文不足 60%（点悬浮开关可强制），或内容都在代码块里
